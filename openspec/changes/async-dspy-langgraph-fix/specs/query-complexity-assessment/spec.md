# Spec: Dynamic Query Planning

**Domain**: agent-runtime
**Generated**: 2026-02-01
**Status**: Draft

## 1. Purpose

Define the dynamic query planning system where the LLM generates an execution plan based on query complexity, available knowledge, and information gaps. The plan DYNAMICALLY determines which workers to create via Send API.

**Problem Statement**: R014 uses a fixed 8-phase pipeline regardless of query complexity. Even "What's 2+2?" goes through multi-hop research, widget selection, and sequencing.

**Success Criteria**:
- Simple queries: Plan returns zero research tasks → direct answer (< 5s)
- Moderate queries: Plan returns 1-3 research tasks → single pass (< 20s)
- Complex queries: Plan returns multi-stage research → iterative execution (< 60s)

---

## 2. Scope

### In Scope

- LLM generates execution plan (not static classification)
- Plan includes: research tasks, information gaps, expected depth
- Input path awareness (text vs STT) affects planning
- Structured output for Send API integration

### Out of Scope

- Send API worker creation (see dynamic-routing spec)
- STT preprocessing (see stt-preprocessing spec)
- Widget selection (see adaptive-widget-selection spec)

```python
# domain/models/query_plan.py
from pydantic import BaseModel, Field
from typing import Literal, Optional
from enum import Enum

class InputPath(str, Enum):
    """Where the query came from - affects planning."""
    TEXT = "text"                 # Clean, well-formed input
    STT = "stt"                   # Noisy, episodic, needs preprocessing

class TaskType(str, Enum):
    """Types of research tasks."""
    SEARCH = "search"             # Web search
    CONTEXTUALIZE = "contextualize"  # Rerank/filter results
    VALIDATE = "validate"         # Cross-check facts
    SYNTHESIZE = "synthesize"     # Combine findings

class ResearchTask(BaseModel):
    """A single research task in the execution plan."""
    task_id: str = Field(description="Unique task identifier")
    task_type: TaskType = Field(description="Type of research task")
    query: str = Field(description="Search/query string for this task")
    dependencies: list[str] = Field(
        default_factory=list,
        description="Task IDs this depends on (for staged execution)"
    )
    priority: int = Field(
        ge=1, le=5,
        description="Priority: 1=highest, 5=lowest"
    )
    expected_duration: float = Field(
        description="Expected duration in seconds"
    )
    cached: bool = Field(
        default=False,
        description="True if result exists in Mem0 memory (skip execution)"
    )
    memory_id: str | None = Field(
        default=None,
        description="Mem0 memory ID if cached, otherwise None"
    )

class ExecutionPlan(BaseModel):
    """Dynamic execution plan generated by LLM."""
    input_path: InputPath = Field(description="Source: text or STT")
    original_query: str = Field(description="User's original query")

    # Core planning
    requires_preprocessing: bool = Field(
        description="Whether STT preprocessing is needed"
    )
    research_tasks: list[ResearchTask] = Field(
        default_factory=list,
        description="Dynamic list of research tasks (0 = simple query)"
    )

    # Memory integration (LangGraph Store - long-term cached research)
    memory_context: dict[str, str] = Field(
        default_factory=dict,
        description="Relevant cached research from Store: {memory_id: summary}"
    )
    cached_tasks_count: int = Field(
        default=0,
        description="Number of tasks with cached results in Store"
    )
    relevant_previous_queries: list[str] = Field(
        default_factory=list,
        description="Previous similar queries found in Store (semantic search)"
    )

    # State tracking
    estimated_depth: Literal["shallow", "medium", "deep"] = Field(
        description="Expected research depth"
    )
    expected_duration: float = Field(
        description="Total expected duration in seconds (reduced by cache hits)"
    )
    confidence_can_answer: float = Field(
        ge=0.0, le=1.0,
        description="LLM's confidence it can answer (increased by cache hits)"
    )

    # Information gaps
    information_gaps: list[str] = Field(
        default_factory=list,
        description="What information is missing (reduced by memory lookup)"
    )

    # Reasoning
    reasoning: str = Field(
        description="Why this plan was chosen (includes memory lookup results)"
    )
```

## 5. API Contract

### 5.1 DSPy Planning Module

```python
# agent/tools/planner/query_planner.py
import dspy
from dspy import InputField, OutputField, Signature

class ResearchTaskSignature(dspy.Signature):
    """Define a research task for the plan."""
    task_type = OutputField(desc="search, contextualize, validate, or synthesize")
    query = OutputField(desc="Search/query string")
    dependencies = OutputField(desc="Comma-separated task IDs this depends on")
    priority = OutputField(desc="Priority 1-5 (1=highest)")

class ExecutionPlanSignature(dspy.Signature):
    """Generate execution plan for query with cached research awareness."""
    query = InputField(desc="The user's query")
    input_path = InputField(desc="Source: text or stt")
    cached_research = InputField(desc="Relevant cached research from Store: {task_id: result_summary}")
    previous_queries = InputField(desc="Previous similar queries found in Store")
    available_knowledge = InputField(desc="What knowledge we already have (from Store + context)")

    # Output fields
    requires_preprocessing = OutputField(desc="true if STT preprocessing needed")
    research_tasks = OutputField(desc="JSON list of research tasks with type, query, dependencies, priority, cached flag")
    estimated_depth = OutputField(desc="shallow, medium, or deep")
    confidence_can_answer = OutputField(desc="0.0 to 1.0 confidence (increased by cache hits)")
    information_gaps = OutputField(desc="What information is still missing (after cache lookup)")
    reasoning = OutputField(desc="Why this plan was chosen (include how cached research influenced decision)")

class QueryPlannerModule(dspy.Module):
    """Generate dynamic execution plan with LangGraph Store integration."""

    def __init__(self, store=None):
        super().__init__()
        self.plan = dspy.Predict(ExecutionPlanSignature)
        self.store = store  # LangGraph Store for cached research

    def _search_store(self, query: str, limit: int = 5) -> dict[str, str]:
        """Search LangGraph Store for relevant previous research results."""
        if not self.store:
            return {}

        # Semantic search in Store namespace ("research", <query_hash>)
        # namespace pattern: ("research", hashlib.sha256(query.lower()).hexdigest())
        import hashlib
        query_hash = hashlib.sha256(query.lower().encode()).hexdigest()
        namespace = ("research", query_hash)

        items = self.store.search(namespace, query=query, limit=limit)
        return {
            item.key: item.value.get("summary", item.value.get("result", ""))
            for item in items
        }

    def forward(self, query: str, input_path: str, available_knowledge: str = "") -> dspy.Prediction:
        """Generate execution plan with cache lookup."""
        cached_research = self._search_store(query)
        previous_queries = list(cached_research.keys()) if cached_research else []

        # Include cached research in available knowledge
        enhanced_knowledge = available_knowledge
        if cached_research:
            cache_text = "\n".join(f"- [{k}]: {v}" for k, v in cached_research.items())
            enhanced_knowledge = f"{available_knowledge}\n\nRelevant cached research:\n{cache_text}"

        return self.plan(
            query=query,
            input_path=input_path,
            cached_research=str(cached_research),
            previous_queries=str(previous_queries),
            available_knowledge=enhanced_knowledge
        )

    async def aforward(self, query: str, input_path: str, available_knowledge: str = "") -> dspy.Prediction:
        """Async plan generation with cache lookup."""
        cached_research = {}
        if self.store:
            import hashlib
            query_hash = hashlib.sha256(query.lower().encode()).hexdigest()
            namespace = ("research", query_hash)

            items = await self.store.asearch(namespace, query=query, limit=5)
            cached_research = {
                item.key: item.value.get("summary", item.value.get("result", ""))
                for item in items
            }

        previous_queries = list(cached_research.keys()) if cached_research else []
        enhanced_knowledge = available_knowledge
        if cached_research:
            cache_text = "\n".join(f"- [{k}]: {v}" for k, v in cached_research.items())
            enhanced_knowledge = f"{available_knowledge}\n\nRelevant cached research:\n{cache_text}"

        return await self.plan.acall(
            query=query,
            input_path=input_path,
            cached_research=str(cached_research),
            previous_queries=str(previous_queries),
            available_knowledge=enhanced_knowledge
        )
```

## 6. Business Rules

| Rule | Description | Enforcement | Source |
|------|-------------|-------------|--------|
| BR-QP-001 | Zero research tasks → direct answer (no Send) | Worker creation checks list | Performance |
| BR-QP-002 | STT input → requires_preprocessing=true | Planner sets flag | STT handling |
| BR-QP-003 | High confidence (> 0.8) → fewer tasks | Planner reasoning | Efficiency |
| BR-QP-004 | Complex queries → staged execution via dependencies | Send API respects dependencies | Correctness |
| BR-QP-005 | LangGraph Store checked FIRST before planning | QueryPlannerModule._search_store() | Cache-first |
| BR-QP-006 | Cached tasks marked with cached=True + memory_id | Planner sets flags on ResearchTask | Skip execution |
| BR-QP-007 | Task results stored in Store after execution | Worker nodes call store.put() | Future cache |
| BR-QP-008 | Store namespace: ("research", query_hash) for semantic search | Store configuration | Organization |
